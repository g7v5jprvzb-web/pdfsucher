# PDFSucher 1.3.7 (Build 15)

- **Dateigröße und Änderungsdatum hinter dem Dateinamen.** In Einstellungen › Allgemein › Trefferraster gibt es zwei neue Schalter: „Dateigröße hinter dem Dateinamen zeigen“ und „Änderungsdatum hinter dem Dateinamen zeigen“. Eingeschaltet steht hinter dem Dateinamen jeder Reihe z. B. „2,4 MB · 14.11.2026, 09:12“ (deutsche Schreibweise). Beide sind anfangs aus.
